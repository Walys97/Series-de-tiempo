# Documento escrito

Entregable escrito del seminario.

- `Seminario_ARIMAX.tex`: fuente LaTeX (se escribe en Overleaf).
- `figuras/`: gráficos que usa el `.tex`. Son los mismos que genera el notebook en `../figuras`.

En Overleaf: subir el `.tex` y los PDF de `figuras/` (en una carpeta `figuras` o en la raíz),
y el `escudo.jpg` si se quiere el escudo en la portada.

Para compilar localmente: `pdflatex Seminario_ARIMAX.tex` dentro de esta carpeta (dos veces,
para que salgan bien las referencias a tablas y figuras).
